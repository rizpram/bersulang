# Font Note

Website ini menggunakan font stack berikut:

```css
font-family: "Akzidenz Grotesk Next", Arial, Helvetica, sans-serif;
```

File font mentah tidak disimpan di repo publik agar tidak membagikan font secara tidak sengaja.

Jika Akzidenz Grotesk Next sudah terpasang di perangkat pengunjung, browser akan memakainya. Jika belum, browser fallback ke Arial/Helvetica.

Untuk membuat font tampil konsisten ke semua pengunjung, tambahkan webfont hanya setelah lisensi web/public untuk font tersebut sudah dipastikan aman.
